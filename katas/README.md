# Katas

Manual coding. **No AI, no autocomplete suggestions.** Timebox each one to 10–15 minutes.

Each file has a spec in its comment and a stub that throws. Make its test pass:

```bash
npx vitest run 01      # one kata
npx vitest 01          # watch mode while you work
```

Talk out loud while you write: what the input is, what edge cases you see, why you chose
the approach. That is what an interviewer listens for.

Reset a kata to start over:

```bash
git checkout -- src/01-split-bill.ts
```
